## Official simulator procedure

```bash
npm run dev &
xvfb-run -a node_modules/@evenrealities/sim-linux-x64/bin/evenhub-simulator --automation-port 9898 "http://127.0.0.1:5173/?demo=reset" &
node scripts/sim-capture.mjs
```

The script drives `/api/input` (up/down/click/double_click), polls `/api/console` for `[questling/screen]` markers and `[questling/glasses]` render failures, and saves `/api/screenshot/glasses` RGBA framebuffers. Observed on 0.9.5: index-0 list selections arrive without `currentSelectItemIndex` (handled), single taps as a type-less `sysEvent` (handled), double-tap `eventType: 3`.

Defects found and fixed through the simulator runs: inbox rows with `·`/`—` exceeded the SDK’s 63-byte list-item limit and the page was rejected (now clipped by bytes for every list, with a regression test); an unsolicited notice could cover the quest-detail screen; a delivered meeting reminder did not start the global cooldown; back-navigation after completing from quest detail returned to the finished quest; the first check-in ran before the calendar loaded.

Set up the services you want in `.env` (see `docs/DEPLOYMENT.md`), run `npm run dev`, and connect them from *Camp* in the app.
